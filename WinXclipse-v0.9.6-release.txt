# WinXclipse v0.9.6

## Reinstall required: back up first

**The APK signing key changed. If you are using the old key, including the original 0.9.5, you must uninstall the old APK and reinstall this version. Uninstalling deletes the app's private data.**

Before uninstalling, export your **saves and full containers**, and back up settings and control presets. Verify the backups and copy them to shared storage or a computer, outside the app's private folders. A community configuration ZIP is not a full container/save backup. Restore your backups after installing the new APK.

Recent local 0.9.6 builds already use this key and do not require this migration.

## Highlights

- Vulkan compositor, optional DisplayX, more video controls and configurable OpenGL drivers.
- Faster Wine/Proton preparation, working installation progress and corrected runtime downloads.
- Reworked sidebar, aligned switches, rounded controls and editable defaults for new containers.
- Expanded HUD with consistent RAM readings, temperatures, swap and power measurements.
- Improved FSR, file transfers, physical mouse/keyboard input and stability.
- Automatic community-config publication with confirmed withdrawal.

The four APKs below provide the same features: **WinXclipse, Antutu, Geekbench and PUBG**.

See [CHANGELOG.md](https://github.com/avavo/WinXclipse/blob/v0.9.6/CHANGELOG.md#096) for all changes and known limits. DisplayX, Frame Generation and game compatibility remain experimental; full RE9/DXVK validation is still pending.
