WinXclipse v0.9 

This release expands the foundation introduced in WinXclipse v0.8.6, with a focus on AMD FSR 1.1 upscaling, Video Configuration, shortcut artwork, touchscreen controls, experimental Exynos/Xclipse performance tuning, ARM64EC compatibility, and container stability.

What Changed Compared to v0.8.6 AMD FSR 1.1 Added AMD FSR 1.1 upscaling using EASU and RCAS. Added real guest render scaling through display and factor controls, allowing the guest application to render at a lower internal resolution for actual GPU performance gains. Added live desktop resizing when changing FSR scaling. Added per-container and per-shortcut FSR configuration through Video Configuration. FSR can provide significant performance improvements in GPU-bound applications and games, including Resident Evil 2. Fixed window and fullscreen letterboxing when switching FSR settings during runtime. Sidebar Display is now view-only for anti-aliasing settings. Video Configuration Added a dedicated Video Configuration interface for containers and shortcuts. Added renderer selection for Vulkan, OpenGL, and GDI. Added GPU name display. Added present mode selection. Added texture filtering configuration. Added vkBasalt sharpness controls. Added CAS and DLS sharpness options with level and denoise controls. Added refresh rate configuration. Added audio driver configuration with volume control. Shortcut Artwork Added SteamGridDB artwork browsing. Added automatic EXE icon extraction. Added support for custom shortcut image sources. Shortcut artwork can now be selected directly from the shortcut configuration. Touchscreen Controls Added a new dark glass-style touchscreen control interface. Added a complete gamepad skin set. Touchscreen haptics are now enabled by default. Improved touchscreen control presentation and interaction. Experimental Performance Expanded the Experimental Performance system for Exynos/Xclipse devices. Added per-model VRAM caps tuned for supported Exynos/Xclipse configurations. Added BCn backend tuning for Xclipse GPUs. Added CPU cluster scheduling adjustments for big.LITTLE and DynamIQ Exynos SoCs. Added unified-memory-aware defaults for Xclipse devices. Performance behavior remains experimental and depends on the device, driver, wrapper, runtime, and game. ARM64EC, Wine and Proton Added ARM64EC compatibility fixes. Improved compatibility with ARM64EC Wine and Proton runtimes. Hardened X server initialization and runtime behavior. Fixed container boot issues with raw Wine and Proton .tzst runtimes. Improved stability when loading external runtime packages. Package Variants Main: com.win.xclipse AnTuTu: com.antutu.ABenchMark Geekbench 6: com.primatelabs.geekbench6 PUBG Mobile: com.tencent.ig
